## Architecture

**SmartCloset AI** is a Flutter mobile app (Android-first, portrait-only) for AI-powered wardrobe management. UI language is Turkish; codebase is in English.

### Tech Stack
- **State management:** Flutter Riverpod 2.5.1 (`ProviderScope` wraps the app in `main.dart`)
- **Auth:** Firebase Auth (email/password + email verification)
- **Local DB:** SQLite via `sqflite` — all clothing inventory is stored locally
- **AI:** Gemini 1.5 Flash Vision API — outfit analysis from images or URLs
- **Weather:** WeatherAPI.com + `geolocator` for location-based outfit suggestions
- **Inspiration:** Unsplash API — infinite scroll fashion feed with AI analysis

### Key Patterns

**Auth flow:** `SplashScreen` → `Firebase.authStateChanges()` → LoginScreen / VerifyEmailScreen (polls every 3s) / HomeScreen.

**State updates:** CRUD goes through `ClothingActions` (in `clothing_provider.dart`), which calls `DatabaseService` then calls `ref.invalidate()` on `clothingListProvider` and `clothingCountProvider` to trigger UI refresh.

**AI analysis:** `AiService` compresses images to 512px / JPEG 60% before sending to Gemini. Returns `OutfitAnalysis` with `overallStyle`, `occasion`, and a list of `AnalyzedPiece` objects — each piece includes auto-generated store links for Trendyol, Zara, H&M, and Mango.

**Weather tags:** Temperature ranges map to `very_cold / cold / mild / warm / hot`, used to tag clothing items and generate Turkish outfit suggestions.
